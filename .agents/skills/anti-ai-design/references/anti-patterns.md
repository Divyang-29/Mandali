# Anti-Patterns vs. Human-Crafted Solutions

This reference catalog contrasts common generic AI design mistakes with bespoke, high-trust human engineering solutions.

| Dimension | Generic AI Cliché (Banned) | Human-Crafted Solution (Enforced) |
| :--- | :--- | :--- |
| **Color Palettes** | High-saturation purple/cyan or neon gradients across every card and button. | Grounded, high-trust palette (e.g., Midnight Navy `#0B192C`, Warm Sandstone `#F8F7F4`, with a single intentional accent like Heritage Saffron `#D97706`). |
| **Hero Sections** | Centered generic text, a floating gradient blob in the background, and a stock 3D sphere or laptop graphic. | Asymmetrical, high-impact typography with a fully functional, responsive interactive product mockup (e.g. live filterable job cards, verified employee timelines). |
| **Card Grids** | 6 identical cards with arbitrary rounded corners, each featuring a monochrome icon and 2 vague sentences. | Varied information density: Bento-style layouts, interactive tabs, expandable previews, and structured metadata tags. |
| **Mobile Adaptability** | Hiding the entire product preview on mobile devices (`hidden sm:flex`) because it doesn't fit. | Responsive-first engineering: scaling mockups fluidly so mobile visitors experience full visual proof and interactive previews. |
| **Typography** | Generic system sans with standard browser tracking, loose headlines, and long unconstrained body widths. | Strict hierarchy: `Plus Jakarta Sans` with tight tracking (`-0.02em`) on display headlines, `Inter` for hyper-legible UI, and `Newsreader` italic for authentic quotes. |
| **Buttons & CTAs** | Pulsing neon glowing borders with generic "Get Started" buttons that link nowhere. | Tactile, deliberate buttons with subtle hover lift (`active:scale-[0.98]`), micro-icons, and functional modal/scroll destinations. |
| **User Onboarding** | Monolithic text walls with plain numbered circles. | Dual-perspective tabs, interactive state switchers, and clear parallel action steps tailored to distinct user roles (e.g., Owners vs Employees). |
| **Data & Social Proof** | Generic counters ("10k+ happy users") without context or sources. | Authoritative metrics backed by verified industry citations (e.g., NACS 2025–2026 data points with expandable methodology notes). |
