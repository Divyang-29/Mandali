# Anti-AI Design Skill

**Skill Name:** `anti-ai-design`  
**Version:** `1.0.0`  
**Scope:** Workspace-level frontend design standard

## Overview
This skill instructs the agent to enforce bespoke, high-craft, human-designed frontend experiences and strictly eliminates generic AI-generated aesthetic clichés (purple mesh gradients, floating blurry blobs, excessive glassmorphism, glowing neon borders, repetitive rounded cards, and cookie-cutter SaaS templates).

## Key Capabilities
- Enforces strict typography hierarchies (Plus Jakarta Sans + Inter + Newsreader).
- Mandates niche-specific layouts and authentic UI mockups.
- Eliminates 404 dead links, broken stubs, and orphan grid slots.
- Guarantees full mobile responsiveness (never hides key product visuals on small screens).
- Integrates pre-flight design system locking and post-flight "AI Slop Removal" auditing.

## Activation
- **Automatic:** Applied to all frontend component creation and styling in this repository via `AGENTS.md`.
- **Manual:** Trigger by typing `anti-ai-design`, `anti-ai`, or asking for a *"design audit"*.
